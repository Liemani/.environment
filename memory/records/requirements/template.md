# Requirements Template

This document contains a copyable template and guidance for creating requirement records.
Copy only the fenced block under `## Template` when creating a new record.

## Template

```md
---
status: Draft
updated: YYYY-MM-DD
---

# <Requirement Title>

<Short statement of the requirement>

## Requirement

<What must be true in the project>

## Acceptance Criteria

- <criterion 1>
- <criterion 2>
```

## Guide

### What this record is

Requirement records define what must be true in the project.

### Important fields

#### status

- Current state of the requirement.
- `Draft` is the default starting state.

#### updated

- Last meaningful update date. Use `YYYY-MM-DD`.

### Requirement

- State the requirement clearly and directly.
- Keep it separate from the acceptance criteria.

### Acceptance Criteria

- List observable conditions that show the requirement is satisfied.
- Keep criteria testable and specific.
