# Docs Template

This document contains a copyable template and guidance for creating supporting documents.
Copy only the fenced block under `## Template` when creating a new document.

## Template

```md
---
updated: YYYY-MM-DD
---

# <Document Title>

<Short purpose>

## Context

<What this document is for>

## Content

<Main content>
```

## Guide

### What this record is

Docs capture supporting material that does not fit a narrower record type.

### Important fields

#### updated

- Last meaningful update date. Use `YYYY-MM-DD`.

### Context

- State the role of the document.
- Keep the scope clear so the reader knows why it exists.

### Content

- Put the main material here.
- Keep the body focused on the purpose named above.
