# Wiki Template

This document contains a copyable template and guidance for creating wiki pages.
Copy only the fenced block under `## Template` when creating a new page.

## Template

```md
---
updated: YYYY-MM-DD
---

# <Wiki Title>

<Short purpose>

## Context

<Relevant background or explanation>

## Notes

<Useful details>
```

## Guide

### What this record is

Wiki pages capture context and reference material that supports the project.

### Important fields

#### updated

- Last meaningful update date. Use `YYYY-MM-DD`.

### Context

- Use this section for background, framing, or scope.
- Keep the page anchored to the reason it exists.

### Notes

- Use this section for details that are useful to revisit later.
- Keep notes concise enough to scan quickly.
